## 核心功能 E2E 流程

### 流程 1: 新用户引导

```
Landing 页 → 开始使用 → Onboarding 选性别 → 选角色 → 完成 → 聊天界面
```

- ✅ Landing 页正常渲染
- ✅ Onboarding 进度条正常
- ✅ 角色选择高亮
- ✅ 开场白预览
- ✅ 完成后进入聊天界面

### 流程 2: 聊天交互

```
选择对话 → 发送消息 → 收到回复 → 复制消息 → 加入记忆 → 重生成
```

- ✅ 消息发送后显示在聊天区
- ✅ 无 API Key 时显示配置提示
- ✅ 消息操作菜单（复制/记住/重生成/删除）
- ✅ 加入记忆后资料面板显示

### 流程 3: 资料与关系

```
打开资料面板 → 查看性格 → 查看关系 → 查看记忆 → 查看动态
```

- ✅ 性格描述显示
- ✅ 亲密度/轮次/连续天数
- ✅ 记忆列表（空状态提示）
- ✅ 动态列表（空状态提示）

### 流程 4: 设置与主题

```
打开设置 → 切换 API 预设 → 修改温度 → 切换暗色 → 保存
```

- ✅ API 预设切换（6 个选项）
- ✅ 温度滑块 0-2
- ✅ 暗色主题全局切换
- ✅ 保存后 Toast 提示
- ✅ 刷新后设置保持

### 流程 5: 数据持久化

```
创建角色 → 发送消息 → 刷新页面 → 数据保持
```

- ✅ 角色列表保持
- ✅ 聊天记录保持
- ✅ 关系状态保持
- ✅ 设置保持
