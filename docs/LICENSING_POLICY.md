# EchoChat Licensing Policy

## 目的

本文档说明 EchoChat 仓库许可证的选择原则、当前状态和未来调整方向。

EchoChat 已进入长期产品化开发阶段，不再以临时 Demo / 实验项目方式维护。
许可证需要保护项目权利人的权利，同时允许社区学习、研究和贡献。

## 选择原则

### 必须保留的权利

- 项目权利人保留源代码的版权和最终控制权
- 项目权利人保留决定商业发行形式的权利
- 项目权利人保留修改许可证的权利
- 官方品牌、Logo、名称独立于源码许可证管理

### 必须允许的使用

- 个人学习和阅读源码
- 本地运行和非商业测试
- 非商业研究
- Fork 和 Bug 修复
- 为 EchoChat 提交贡献

### 必须限制的使用

未经项目所有者明确授权，不允许：

- 将 EchoChat 整体或主要部分重新包装成独立商业产品
- 直接复制 EchoChat 官方产品并重新发布
- 移除版权声明后重新发行
- 使用 EchoChat 官方品牌、Logo、名称暗示官方关系
- 将官方产品资产作为自己的品牌资产
- 将本仓库作为另一个商业产品的核心代码直接再发行

## 当前许可证

EchoChat 当前采用 **PolyForm Noncommercial License 1.0.0**。

选择理由：

1. **标准许可证**：PolyForm 是由专业法律团队起草的标准源码可用许可证，不是自行创造的模糊许可证
2. **非商业核心**：明确允许非商业使用、修改和分发，禁止商业使用
3. **版权保留**：保留版权声明要求，禁止移除版权信息
4. **专利授权**：包含明确的专利授权条款
5. **贡献兼容**：允许社区贡献，贡献代码在同一许可证下合并

### PolyForm Noncommercial 与项目需求的对应

| 项目需求 | PolyForm Noncommercial 覆盖 |
|---------|---------------------------|
| 个人学习 / 本地运行 | ✅ 允许 |
| 非商业研究 / 测试 | ✅ 允许 |
| Fork / Bug 修复 | ✅ 允许（非商业分发） |
| 提交贡献 | ✅ 允许 |
| 禁止商业再发行 | ✅ 禁止商业使用 |
| 禁止移除版权声明 | ✅ 要求保留版权声明 |
| 品牌使用限制 | ⚠️ 由 TRADEMARKS.md 单独管理 |

## 品牌独立原则

EchoChat 官方品牌（名称、Logo、视觉识别）**不**随源码许可证自动授权。
即使源码许可证允许修改和分发，使用官方品牌仍需遵守 `TRADEMARKS.md`。

## 未来调整

项目权利人保留根据项目发展阶段调整许可证的权利。可能的调整方向包括：

- 特定版本采用更宽松的许可证（如 Apache 2.0）
- 核心代码与插件代码采用不同许可证
- 商业发行采用单独的商业许可证
- 引入 Contributor License Agreement (CLA)

任何许可证调整将：
1. 提前在仓库中公告
2. 不影响已发布版本的既有授权
3. 获得主要贡献者的同意（如适用）

## 第三方依赖

EchoChat 使用的第三方依赖遵循其各自的许可证。详见 `THIRD_PARTY_NOTICES.md`。
第三方依赖的许可证不影响 EchoChat 自身源码的许可证。

## 贡献者权利

贡献者提交代码即表示同意其贡献在 EchoChat 仓库许可证下使用。
详见 `CONTRIBUTING.md` 中的 Contributor Terms。

## 疑问

关于许可证的疑问，请通过 GitHub Issue 联系项目维护者。
商业授权咨询请直接联系项目权利人。
