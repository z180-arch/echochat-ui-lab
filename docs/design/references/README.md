# Design references

Mechanisms only. No third-party code, logos, or page clones.

### Quiet messenger presence

- **What we learned:** Identity lives in the header (face + name + a short status). The transcript is paper, not chrome. Grouped bubbles; timestamps are metadata.
- **What we did not copy:** WeChat green bubbles, iMessage lock-screen, read receipts, sticker rails.
- **How it applies:** EchoChat Chat drops her-bubble shadows and keeps mint as *our* paper, not as chat-app branding.

### Journal / diary grouping

- **What we learned:** Lived history groups by day, not by a media grid. Empty pages are a blank book, not a dashed “no data” illustration.
- **What we did not copy:** Social like/comment as the point of the surface.
- **How it applies:** Moments stay day-railed; actions stay quiet.

### Calm settings

- **What we learned:** Controls can be dense without becoming iOS Settings if identity is editorial and groups are typographic.
- **What we did not copy:** Inset grouped tables as the only language.
- **How it applies:** 我的 identity header without a card; rows remain 44px for a11y.
