# SillyTavern

- **Repository:** https://github.com/SillyTavern/SillyTavern  
- **License:** AGPL-3.0  
- **What it solves:** Power-user LLM front-end for long character roleplay.  
- **Interesting mechanism:** World Info / lorebook keyword injection; ordered prompt assembly; persona + character card stack; extension ecosystem; context budget craft.  
- **Interesting UX:** Density and control; assumes the user is an engineer-author.  
- **Interesting architecture:** Client-heavy JS app with deep prompt orchestration (not a quiet companion product).  
- **What EchoChat could learn:** Lore/world as **conditional background retrieval**; continuity needs structured injection, not raw infinite scroll alone.  
- **What EchoChat should NOT copy:** Extension markets, prompt DSLs as primary UX, AGPL code, “power user workbench” IA.  
- **Continuity question:** Does it make the *character’s behavior* continuous for a quiet user? Only if the user configures it — fails our Primary Human.
