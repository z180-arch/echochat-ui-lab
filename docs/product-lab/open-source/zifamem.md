# ZifaMem

- **Repository:** https://github.com/zifacorp/zifamem  
- **License:** Unspecified on GitHub metadata at research time — treat as **no code reuse**.  
- **What it solves:** Emotional long-term memory for companions: not only facts, but how the relationship felt.  
- **Interesting mechanism:** Structured layers (session / episodic / user model); reinforcement, decay, merge/reflection as lifecycle; relationship-centered organization.  
- **Interesting UX:** Framework/SDK oriented; companion products must wrap it.  
- **Interesting architecture:** Python memory framework; evaluates emotional continuity vs raw history.  
- **What EchoChat could learn:** Memory alone ≠ companion continuity; pair facts with **relationship state**; lifecycle > infinite transcript.  
- **What EchoChat should NOT copy:** New Python service dependency; cloud evaluation stack; unclear license code.  
- **Continuity question:** Directly aligned with EchoChat Primary Bet (Memory × Relationship) at the *idea* layer.
